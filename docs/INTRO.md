# Meowmorize

**一个按遗忘曲线决定「今天背多少」的 Android 背诵工具。**

它不问你「还有多少没背」，而是先算清楚「你今天能背多少」，再把最该背的塞进去。
多出来的部分主动顺延——不是偷懒，是不让你在第三天就放弃。

- 平台：Android 10 及以上（minSdk 29）
- 技术：Kotlin · Jetpack Compose · Room · Hilt · DataStore
- 许可：MIT（图标素材除外，见文末）
- 状态：v1.0.2，可安装使用；算法有 63 个单元测试守边界

---

## 一、它想解决什么

用间隔重复的人大多经历过这个循环：

1. 兴致勃勃导入几百条内容；
2. 三天没打开，回来发现到期 200 条；
3. 挑着背了 20 条，剩下 180 条继续滚雪球；
4. 一周后彻底不打开了。

问题不在「记不住」，而在**算法只懂记忆，不懂人**。
所有主流工具回答的是「这条内容什么时候该复习」，没有回答「今天这 30 分钟该复习哪几条」。

Meowmorize 把这两件事分开：

| 问题 | 由谁回答 |
| --- | --- |
| 这条内容什么时候该再见？ | FSRS 遗忘曲线（稳定性 / 难度） |
| 今天总共能做多少？ | 弹性容量（负荷偏好 × 状态 × 完成率 × 周末） |
| 今天先做哪几条？ | 逾期 → 优先级 → 回忆概率 → 到期时间 |
| 放不下的怎么办？ | 顺延，并明确告诉你顺延了多少 |

## 二、三个核心机制

### 1. 排程：FSRS-4.5 的简化实现

每条内容维护两个量：稳定性 `S`（天）与难度 `D`（1~10）。

```
回忆概率   R(t, S) = (1 + 19/81 · t / S) ^ -0.5
反解间隔   I(S, r) = S / (19/81) · (r^(1/-0.5) − 1)
```

`t = S` 时 `R = 0.9`，这就是「目标保持率 90%」的含义：让复习发生在快忘记的边缘，而不是固定隔几天。

在此基础上补了几处主流实现容易算错的地方：

- **同日重练用真实分钟**：点「忘了」是 10 分钟后重来，不是被当成 0.25 天（6 小时）——后者会把回忆概率从 0.999 压到 0.98，连点几次就系统性高估遗忘；
- **逾期有补偿**：逾期 10 天还记得，稳定性应该多涨一点（最多 +10%，30 天封顶），否则长期欠账永远收不回来；
- **四档只调间隔，不重复调稳定性**：`HARD/EASY` 若同时乘稳定性和难度，等于同一件事罚两遍；
- **步进有上限**：一天内超过 3 次「忘了」就冷却 6 小时，避免用蛮力刷同一张卡。

### 2. 弹性：今天背多少，是一个可解释的决定

```
factor = 负荷偏好 × 今天状态 × 完成率(或趋势) × 周末
factor = clamp(factor, 0.60, 1.25)
if (到期分钟 > 2 × 基准容量) factor = min(factor, 0.90)
有效容量 = round(基准容量 × factor)
```

约束比公式重要：

- 有积压时，**复习最多占 80%**，新学只填剩下的空间；
- 容量连一条都装不下时，选**最短**的那条，而不是排序第一条；
- 所有调整都会生成一句人话，例如「近 3 天按分钟算的完成率在下滑（42%），今天先降 10%」。

### 3. 复习：先回忆，再决定

- 点开只看到题干，内容默认遮住；
- 可以写「背诵提示」，但**用过提示就不能选「轻松」**——降难度要付代价；
- 点任意熟练度 → 立刻展开答案，该按钮变成「下一步」；可以改选；确认后才写日志；
- 出结果后**四个按钮整体锁定**，避免连点把间隔推到几个月后。

填空题单独处理：题干（如「第二次世界大战的特点为 ______」）始终可见，只有答案需要点「显示答案」。这才像考试。

## 三、功能一览

| 模块 | 能做什么 |
| --- | --- |
| 今日 | 今日清单、剩余时长、进度环、算法解释、一键调整任务量、状态三档（累/正常/状态好） |
| 日历 | 月视图 + 每日清单；历史看真实记录，未来看预测；学科色点 + 负荷底色 |
| 任务库 | 搜索、学科筛选、6 种排序（最近更新/创建、下次复习、主题拼音、时长、优先级）、归档、删除、管理学科 |
| 编辑器 | 学科、主题、内容、来源、优先级、截止日期、背诵提示、用时（自动估算可覆盖）、Markdown、填空题、OCR（测试） |
| 设置 | 容量、新任务上限、目标保持率、自动减负、周末放宽；复习算法参数；三项弹性实验；界面风格；日历同步；时间快进（测试） |

两套视觉可按需切换：

- **柔角卡片**（默认）：大圆角、暖橙强调、环形进度，偏生活化；
- **终端仪表盘**：深蓝黑底、规格条 + 记忆保持曲线 + 近 7 天负载柱、3–10dp 圆角、数字用等宽字体。

## 四、技术实现

12 个模块，依赖严格单向：`feature → domain → model`，UI 不直接依赖 `:core:data`。

| 层 | 模块 | 内容 |
| --- | --- | --- |
| 壳 | `:app` | NavHost、主题注入、启动引导 |
| 功能 | `:feature:{today,calendar,library,editor,settings}` | Compose 页面 + HiltViewModel + 单一 UiState |
| 设计系统 | `:core:designsystem` | 主题、卡片、图表、输入、自绘底部弹层 |
| 领域 | `:core:domain` | FSRS、弹性策略、排序、配额、用例、仓库接口（纯 Kotlin，可 JVM 单测） |
| 数据 | `:core:data` / `:core:database` | 仓库实现、DataStore、Room 实体与迁移、日历适配、可调时钟 |

两个刻意的设计：

- **内容与记忆进度分表**：改内容（改错别字 / 重写）不会破坏已有复习进度；
- **数据库只加不删**：每次迁移都带默认值并提交 schema，新装与升级得到完全一致的表结构。

数据全部留在本机，没有账号，也不上传任何内容。

## 五、安装

1. 打开 [Releases](https://github.com/feitianwuhu/Meowmorize/releases/latest)，下载 `Meowmorize.apk`；
2. 允许「安装未知来源应用」；
3. 需要 Android 10 及以上。

```bash
# 校验
sha256sum Meowmorize.apk
```

签名 `CN=Meowmorize`，升级必须用同一密钥，否则只能卸载重装（数据会丢）。
调试版包名带 `.debug`，可与正式版共存。

## 六、已知限制

- **未做真机全量验证**：开发机没有模拟器，交互细节与部分 ROM 的兼容性靠用户反馈推进；
- **OCR 依赖 Google Play 服务**：国产 ROM 上可能不可用，界面会提示改用「粘贴文本」；
- **当前版本关闭了 R8**：不混淆、不裁剪，体积 51MB；等实机验证充分后再打开；
- 统计与提醒尚未做：`review_logs` 已存够字段，缺一个统计页和 WorkManager 调度。
